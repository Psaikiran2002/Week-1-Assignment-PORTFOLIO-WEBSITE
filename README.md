# Week-1-Assignment-PORTFOLIO-WEBSITE

### Objective
Build a responsive, accessible personal portfolio website from my resume that presents my skills, projects, education and contact details.

### Tech Stack
- HTML5 (semantic markup)
- CSS3 (Grid, Flexbox, custom properties)
- JavaScript (vanilla, lightweight)
- Google Fonts (Bricolage Grotesque, IBM Plex Sans)

### Features Implemented
- Multi-page layout: Home, About, Projects, Skills, Resume, Blog preview, Testimonials, Contact
- Responsive navigation with a mobile menu and a "More pages" dropdown
- Light / dark theme toggle
- Skip-to-content link and ARIA labels for accessibility
- Technology stack tags and featured project cards
- Scroll-reveal animations
- Downloadable resume (PDF)
